# Recorrido de presentación para Daisy

## Antes de comenzar

“Esta es una versión de revisión para que veamos juntas el estilo, el tono y el recorrido. Aún estamos afinando algunos encuadres y tamaños para que todo se sienta impecable en celular.”

## Recorrido recomendado

1. **Página principal** — Presentar las cuatro formas de florecer, la personalidad cálida de la marca y el acceso sencillo a una ruta según lo que cada mujer necesita.
2. **Belleza que Florece** — Mostrar una experiencia de belleza cercana y sin presión, con caminos claros para descubrir cuidado facial, corporal e imagen personal.
3. **Cuidado Facial** — Explicar cómo una mujer puede reconocer lo que necesita, explorar opciones y pedir orientación para construir una rutina propia.
4. **Cuidado Corporal** — Enseñar una experiencia de autocuidado cotidiano, sensorial y amable, que termina en una invitación clara a conversar.
5. **Vida Natural Bloom** — Presentar hábitos realistas de bienestar, organizados en rutas pequeñas que se pueden incorporar con calma.
6. **Descanso, Calma y Equilibrio** — Cerrar con una página serena, práctica y humana que propone pausas sencillas y acompañamiento sin exigencia.

## Forma de navegación

Usar directamente estas URL y no entregar el control del menú durante la primera revisión:

- `http://127.0.0.1:8000/`
- `http://127.0.0.1:8000/belleza-que-florece/`
- `http://127.0.0.1:8000/belleza-que-florece/cuidado-facial/`
- `http://127.0.0.1:8000/belleza-que-florece/cuidado-corporal/`
- `http://127.0.0.1:8000/vida-natural-bloom/`
- `http://127.0.0.1:8000/vida-natural-bloom/descanso-calma-equilibrio/`

## Recomendación

La alternativa más segura ahora es **A — recorrido guiado local**, después de una corrección CSS acotada. Evita que Daisy llegue accidentalmente a páginas con imágenes faltantes y mantiene claro que está viendo un avance.

Cuando las seis páginas superen la segunda revisión visual, sí conviene preparar **C — staging privado**: copia separada, contraseña cuando sea posible, `noindex, nofollow`, fuera del sitemap y con un aviso discreto de “versión en revisión”. No usar todavía el dominio público principal.
