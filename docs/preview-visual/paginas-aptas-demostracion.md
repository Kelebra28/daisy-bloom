## Navegación segura

Recomendación inmediata: **Alternativa A — recorrido guiado** mediante las seis URL directas. No usar el menú como índice libre. La página local de revisión y el staging privado requieren autorización posterior; el staging solo debe prepararse tras corregir CSS y repetir QA.
