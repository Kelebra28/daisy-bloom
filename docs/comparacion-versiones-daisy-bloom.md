# Comparación de versiones Daisy Bloom

`daisy-bloom-public_html/` es la fuente oficial. Es la única versión con las 22 páginas, 38 imágenes, documentación, sitemap, robots y configuración de Hostinger.

## Conclusiones verificadas

- Los 91 archivos de proyecto presentes en el ZIP coinciden con la carpeta extraída.
- El ZIP agrega metadatos Finder y AppleDouble bajo `__MACOSX/`.
- No existen avances exclusivos en los HTML sueltos.
- Los avances posteriores —enlaces hacia landings ya publicables— están en la fuente oficial.
- No se requiere consolidar contenido desde las versiones anteriores.
